# QuestChromeCraft

Inline Russian quest log / quest giver translation for the WoW 3.3.5a client (Interface 30300).

Install: put the `QuestChromeCraft` folder into `Interface/AddOns/` and restart the game.

- `QuestChromeCraft.lua` - the addon.
- `QuestData_RU.lua` - Russian quest texts by quest id (about 16 MB).
- `QuestTitles_EN.lua` - English quest titles.
- `Fonts/` - fonts used for the Russian text.
